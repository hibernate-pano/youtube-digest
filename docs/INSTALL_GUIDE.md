# YouTube Digest:安装指南(给朋友版)

> 预计耗时:5 分钟(不填 Key 的话)。需要:一台电脑、一个 Chrome 浏览器。
> AI Key 和 GitHub 账号都是可选的。

## 零、先装,后配

**不填任何 Key 也能装完并且立刻用起来。** 按第二节装好扩展,打开一个 YouTube
视频,字幕、搜索、笔记和资料库就能用了,这四样全部在你自己电脑上工作。
面板顶部会写清楚:哪一半已经能用,哪一半在等一个 Key。

需要 AI Key 的是这些:AI 摘要和章节、重点引用、翻译、「讲解」、视频页面上
Note 按钮把字幕整理成一条笔记,以及从字幕里挑出生词。间隔复习需要 GitHub
登录,因为复习计划保存在同步服务上。等你确实要用它们的时候,再回到第一节去
申请,不用现在就办。

## 一、准备 API Key(要用 AI 功能时再看)

YouTube Digest 本身不收费。摘要、翻译、讲解和挑生词需要你自己的**一个 AI
服务的 Key**。

字幕是直接从你正在看的那个 YouTube 页面里读出来的:不用 Key、不消耗额度、字幕文字也不会离开你的浏览器。
只有当页面读不到字幕时,扩展才会退回到 Supadata 兜底,那时候才需要一个 Supadata Key(可选)。
数据只会发给你自己填了 Key 的那些服务;只有你用 GitHub 登录之后,已保存的笔记、生词和复习进度才会同步到本项目自建的同步服务。

1. **AI 服务 Key**(用于 AI 摘要/翻译,DeepSeek / MiniMax / OpenCode Go 任选其一)
   - DeepSeek:打开 https://platform.deepseek.com/api_keys 注册并创建 key
   - 需要充一点点余额(几块钱够用很久,按量计费)
2. **Supadata Key**(可选,只在页面读不到字幕时兜底)
   - 打开 https://dash.supadata.ai/auth/sign-up 注册
   - 注册后自动生成一个 key,复制保存
   - 免费版每月 100 条。填了就多一条退路,没填也完全能用

## 二、安装扩展(5 分钟)

1. 下载项目 ZIP:https://github.com/hibernate-pano/youtube-digest → Code → Download ZIP
2. 解压到固定文件夹(以后不要移动它)。**要选的是直接放着 `manifest.json` 的那一层文件夹**,不是最外层那层带项目名的壳,详见下面的常见问题
3. 打开 Chrome,地址栏输入 chrome://extensions 回车
4. 打开右上角「开发者模式」开关
5. 点「加载已解压的扩展程序」,选择第二步里那个直接放着 `manifest.json` 的文件夹
6. 扩展装好后不会自动出现在工具栏上:点工具栏的拼图图标,在列表里找到 YouTube Digest,点图钉固定它(右键图标也可以)。在 YouTube 页面上点 Digest 按钮,侧边栏同样会打开

## 三、配置(可选,3 分钟)

装完就能用。这一步只在你想要摘要、翻译、讲解和挑生词的时候做。

1. 打开任意 YouTube 视频,点扩展图标打开侧边栏
2. 点右上角 Settings
3. 粘贴 AI 服务的 Key(Supadata Key 可选,可留空),点保存

现在不想填 Key 也可以直接点保存:设置页会把不需要 Key 的那些内容都存下来,
等你什么时候想用摘要、翻译、讲解或挑生词,再回来填一次就行。

> 没有 Key 也能用:字幕、搜索、笔记和资料库都在你自己的机器上工作,面板顶部会告诉你哪一半在等 Key。等你填了 Key,摘要、翻译、讲解和挑生词就会打开。

## 四、使用(1 分钟上手)

1. 打开一个有字幕的 YouTube 视频(英语学习视频最佳)
2. 侧边栏自动显示字幕,可以切换 原文 / 中文 / 双语
3. 点「Summary」看 AI 总结和章节
4. 看视频时按键盘 n 键(或把鼠标移到视频上,点出现的 **Note** 按钮)记笔记

## 五、(可选)开通云同步

1. 在 Settings 里点「Sign in with GitHub」登录
2. 登录之后,你保存的笔记、生词和复习进度会镜像到你自己的同步服务账号 https://ytd.panbo.space/,登录后也可以在网页版查看和管理笔记:https://ytd.panbo.space/
3. 第一次登录时,你在未登录状态下保存的笔记和生词会移入你的账号,设置页会告诉你移了多少条
4. 换电脑/浏览器,重新安装扩展后登录同一账号,数据就回来了
5. 退出登录会停止镜像,并清除这台浏览器上的副本;想彻底删掉,用设置页的「删除我的账号」,它会把账号和它的全部数据从同步服务上删掉
6. 不登录也一样能用,只是笔记只留在这台设备上,不会上传到任何服务器

## 常见问题

### 安装的时候

- **「加载已解压的扩展程序」被拒绝,或者提示清单文件无效**:多半是选错了文件夹。Chrome 要的是扩展的根目录,也就是那个**直接放着 `manifest.json` 的文件夹**。打开你选的文件夹,确认 `manifest.json` 就在第一层,而不是在某个子目录里。
- **解压出来的文件夹里还多了一层**:GitHub 下载的 ZIP 解压后常常是「项目名/项目名/manifest.json」这种双层结构。你要选的是里面那一层(直接有 `manifest.json` 的那层),不是最外面的壳。
- **工具栏上没有出现图标**:扩展装好后不会自动固定在工具栏上。点工具栏的拼图图标,在扩展列表里找到 YouTube Digest,点图钉固定;或者直接打开一个 YouTube 视频,点页面上的 **Digest** 按钮,侧边栏就会打开。
- **装完以后完全找不到扩展**:回到 `chrome://extensions`,确认卡片在列表里、开关是打开的。改了本地文件或者换了新版本之后,记得点卡片上的「重新加载」,再刷新已经打开的 YouTube 页面。

### 用的时候

- **没字幕**:扩展会先从页面读字幕,读不到才用 Supadata 兜底。两个都没有时,面板会直接告诉你「这个视频没有能读到的字幕」,而不是一直转圈
- **AI 报错**:检查 DeepSeek 余额、key 是否粘贴完整
- **更新**:扩展不会自动更新,重新下载 ZIP 覆盖后,在 chrome://extensions 点「重新加载」
